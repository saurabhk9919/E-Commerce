React Shopping Cart Application using modern web technologies. It's a full-featured e-commerce app that lets users browse products, add them to a cart, manage quantities, and place orders.

- **React.js** – Component-based UI development
- **Redux Toolkit** – State management
- **Redux Thunks** – Async data fetching
- **React Router** – Client-side routing
- **localStorage** – Persistent cart state
- **Props & Component Composition**
- **Event Handling & Form Inputs**
- **Array Operations** – `map`, `filter`, `reduce`
